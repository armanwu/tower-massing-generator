# Tower Massing Generator

**Generative Architectural Massing through Geometric Transformation and Environmental Analysis**

## Overview

Tower Massing Generator is a computational design project for exploring architectural tower forms through geometric transformations, generative algorithms, and evolutionary optimization.

Developed using Rhinoceros 3D, Grasshopper, Galapagos, and Ladybug Tools, the project integrates geometric exploration, design optimization, and environmental analysis into an architectural design workflow.

## Key Features

- Geometric transformation: translation, rotation, dilation, and curvature.
- Parametric control of building and floor heights.
- Generative exploration of tower configurations.
- Evolutionary optimization using Galapagos.
- Environmental analysis using Ladybug Tools.

## Software and Tools

- Rhinoceros 3D
- Grasshopper
- Galapagos
- Ladybug Tools

## Objective

To explore the potential of generative design and computational methods in producing diverse architectural tower forms while considering geometric and environmental performance.
